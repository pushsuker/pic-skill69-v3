## 8.2 Backup / Restore ฐานข้อมูล — คนที่ 1

ไฟล์สำรองไปอยู่ที่ `C:\bpes\backups\bpes.sql` (เพราะ compose ผูก `./backups` ไว้กับ `/backup` ใน container ของ db)

```powershell
# สำรองข้อมูล
docker compose exec db sh -c "mysqldump -uroot -proot1234 bpes > /backup/bpes.sql"

# กู้คืนข้อมูล
docker compose exec db sh -c "mysql -uroot -proot1234 bpes < /backup/bpes.sql"
```

สาธิต: สำรอง → phpMyAdmin ลบแถวใน `scores` → กู้คืน → แถวกลับมา

> ใช้ `sh -c "... > /backup/..."` ให้ไฟล์ถูกเขียนใน container อย่าใช้ `>` ของ PowerShell เพราะจะได้ไฟล์ภาษาไทยเพี้ยน

## 8.3 ตัวอย่างเพิ่มฟังก์ชันใหม่: หน้า "สรุปภาพรวม" (ฝึกสูตร เพิ่ม API 1 ตัว + หน้า 1 หน้า)

ทุกฟังก์ชันใหม่ทำ 4 ขั้นเดิมเสมอ: route ใน backend → เปิดใน `server.js` → หน้า `.vue` → เพิ่มใน `App.vue`

**คนที่ 1** สร้างไฟล์

📄 **`backend/routes/stats.js`**

```js
const router = require('express').Router();
const { query } = require('../db');
const { role } = require('../auth');
const { ok, route } = require('../helpers');
// GET /api/stats — สรุปจำนวนผู้ใช้ตามบทบาท และจำนวนรอบตามสถานะ (admin)
router.get(
  '/stats',
  role('admin'),
  route(async (req, res) => {
    ok(res, {
      users: await query('SELECT role, COUNT(*) AS total FROM users GROUP BY role'),
      periods: await query('SELECT status, COUNT(*) AS total FROM periods GROUP BY status'),
    });
  }),
);
module.exports = router;
```

เพิ่มใน `server.js` ต่อจากบรรทัดของขั้น 6

```js
app.use('/api', require('./routes/stats')); // ขั้น 8
```

**คนที่ 2** สร้างไฟล์

📄 **`frontend/src/pages/StatsPage.vue`**

```vue
<template>
  <section>
    <h1>สรุปภาพรวม</h1>
    <div v-if="stats" class="grid">
      <div class="box">
        <h2>ผู้ใช้ตามบทบาท</h2>
        <p v-for="u in stats.users" :key="u.role">
          {{ names[u.role] }}: <strong>{{ u.total }}</strong> คน
        </p>
      </div>
      <div class="box">
        <h2>รอบประเมินตามสถานะ</h2>
        <p v-for="p in stats.periods" :key="p.status">
          {{ p.status }}: <strong>{{ p.total }}</strong> รอบ
        </p>
      </div>
    </div>
  </section>
</template>

<script>
import { api } from '../api';

export default {
  data() {
    return {
      stats: null,
      names: { admin: 'ฝ่ายบุคลากร', evaluatee: 'ผู้รับการประเมิน', evaluator: 'กรรมการ' },
    };
  },
  async mounted() {
    this.stats = await api('/stats');
  },
};
</script>
```

แก้ `App.vue` 4 จุด

```js
// 1) ส่วน import
import StatsPage from './pages/StatsPage.vue';
// 2) ใน components: { ... } เพิ่ม
    StatsPage,
```

```html
<!-- 3) ในเมนูของ admin ต่อจากปุ่ม "ผู้ใช้" -->
<v-btn :variant="page === 'stats' ? 'tonal' : 'text'" @click="go('stats')">สรุปภาพรวม</v-btn>
<!-- 4) ใน <main> ต่อจาก users-page -->
<stats-page v-if="page === 'stats'"></stats-page>
```

เตรียมข้อมูลตัวอย่างให้พร้อมก่อนนำเสนอ (รอบที่มีผลครบและเผยแพร่แล้ว 1 รอบ + รอบฉบับร่าง 1 รอบไว้สาธิตการเพิ่ม) จะได้ไม่ต้องกรอกสดทั้งหมด

**คำถามที่น่าจะโดนถาม เตรียมคำตอบ**

1. JWT คืออะไร ปลอดภัยอย่างไร → token ที่ server ลงนามด้วยกุญแจลับ แก้ไขแล้วลายเซ็นไม่ตรง มีวันหมดอายุ 8 ชั่วโมง
2. เก็บรหัสผ่านอย่างไร → hash ด้วย bcrypt ไม่เก็บตัวจริง
3. คำนวณคะแนนอย่างไร → (คะแนน ÷ คะแนนเต็มของข้อ) × น้ำหนัก รวมทุกข้อ ÷ น้ำหนักรวม × 100 แล้วเฉลี่ยกรรมการทุกคน
4. กันกรรมการแก้คะแนนของคนอื่นอย่างไร → ตรวจ `evaluator_id` ตรงกับผู้ login ใน `own()`
5. ทำไมใช้ Docker → ทุกเครื่องได้สภาพแวดล้อมเหมือนกัน คำสั่งเดียวรันครบ ไม่ต้องลง MySQL/Node เอง
