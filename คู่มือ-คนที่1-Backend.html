คู่มือทีม 3 คน (ฉบับย่อ): ระบบประเมินบุคลากร (รายการที่ 57) รันด้วย Docker

ฉบับย่อ ทำงานครบตามเกณฑ์เหมือนฉบับเต็ม และยังบังคับเปลี่ยนรหัสผ่านครั้งแรก แต่ตัดส่วนที่ยากและไม่มีคะแนนออก: ระบบ token_version, การเตือน "ยังไม่บันทึก" (dirty tracking), ไลบรารี html2pdf (ใช้ปุ่มพิมพ์ → บันทึกเป็น PDF แทน) และแยกหน้ารอบประเมินที่ยาวที่สุดออกเป็น 3 ไฟล์เล็ก

คู่มือนี้พาทำระบบตามโค้ด vue-pic-student ตั้งแต่โฟลเดอร์ว่างจนจบ แบ่งงานให้ 3 คน และเรียงลำดับตาม เกณฑ์ให้คะแนน 100 คะแนน ทุกขั้นจบด้วย จุดเช็ก ถ้าผ่านให้ บันทึก (git commit) ทันที ถ้าขั้นถัดไปพัง ก็ย้อนกลับมาจุดที่ผ่านได้ และระบบยังเปิดโชว์กรรมการได้ คะแนนส่วนก่อนหน้าไม่หาย

โค้ดทุกไฟล์ในคู่มือนี้ทดสอบรันจริงด้วย docker compose ครบทุกขั้นแล้ว (ขั้น 1 ถึง 8) เฉลยที่ทำครบอยู่ในโฟลเดอร์ เฉลย-docker/ ข้างคู่มือนี้ ครูใช้ตรวจ ไม่ควรให้นักเรียนคัดลอกทั้งโฟลเดอร์ตอนฝึก

ทุกจุด "💾 บันทึก" ในคู่มือ ให้ต่อท้ายด้วย git pull และ git push เสมอ เพื่อส่งงานให้เพื่อนในทีม

ถ้าขั้นถัดไปพังและแก้ไม่ทัน ให้กลับไปสภาพที่ผ่านล่าสุด:

git restore .         # ทิ้งการแก้ไขที่ยังไม่ commit ทั้งหมด

ไฟล์ใหม่ที่ยังไม่เคย commit จะยังอยู่ ถ้าต้องการลบให้ลบเองทีละไฟล์ (หรือ git clean -n ดูก่อน แล้ว git clean -f)

  2. Frontend git pull เพื่อเอา backend ล่าสุด แล้วรัน docker compose up -d บนเครื่องตัวเอง ทดสอบหน้าเว็บกับ API จริง
  3. Frontend ผ่านจุดเช็ก → commit/pull/push → บอกทีม
  4. ออกแบบ git pull แล้วทดสอบบนเครื่องตัวเอง จับภาพลง docs/ → commit/pull/push
  5. Backend git pull เพื่อให้เครื่องหลักมีงานครบ ก่อนเริ่มขั้นถัดไป

แต่ละเครื่องมีฐานข้อมูลของตัวเอง (อยู่ใน Docker ของเครื่องนั้น) ข้อมูลทดสอบไม่ปนกัน ไฟล์ที่ไม่ต้องส่ง (node_modules, backend/uploads, ไฟล์สำรอง) ถูกกันไว้แล้วใน .gitignore

4. ถ้าเกิด conflict (ชนกัน)

เกิดเมื่อสองคนแก้บรรทัดเดียวกันในไฟล์เดียวกัน ถ้าทำตามข้อ 1 แทบไม่เกิด ถ้าเกิด git pull จะขึ้น:

CONFLICT (content): Merge conflict in backend/server.js
Automatic merge failed; fix conflicts and then commit the result.

วิธีแก้:

  1. เปิดไฟล์ที่บอกใน VS Code จะเห็นแถบสี <<<<<<< (ของเรา) และ >>>>>>> (ของเพื่อน)
  2. กดปุ่มด้านบนแถบ: Accept Current Change (เก็บของเรา) / Accept Incoming Change (เก็บของเพื่อน) / Accept Both Changes (เก็บทั้งคู่) ให้ เจ้าของไฟล์ เป็นคนตัดสิน
  3. บันทึกไฟล์ ตรวจว่าไม่มี <<<<<<< หลงเหลือ แล้ว:
git add -A
git commit -m "รวมงาน แก้ conflict"
git push

แก้ไม่เป็น หรือกลัวพัง: git merge --abort จะกลับไปสภาพก่อน pull แล้วไปถามเจ้าของไฟล์

-- 8 ตาราง อ่านจากบนลงล่าง ตารางลูกอ้างถึงตารางแม่ด้วย FOREIGN KEY
CREATE TABLE IF NOT EXISTS users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  username VARCHAR(50) NOT NULL UNIQUE,
  password VARCHAR(255) NOT NULL,
  full_name VARCHAR(100) NOT NULL,
  department VARCHAR(100) NOT NULL DEFAULT '',
  position VARCHAR(100) NOT NULL DEFAULT '',
  role ENUM('admin','evaluatee','evaluator') NOT NULL,
  active BOOLEAN NOT NULL DEFAULT TRUE,
  must_change_password BOOLEAN NOT NULL DEFAULT TRUE
);
CREATE TABLE IF NOT EXISTS periods (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  year INT NOT NULL,
  start_date DATE NOT NULL,
  end_date DATE NOT NULL,
  status ENUM('draft','open','closed') NOT NULL DEFAULT 'draft',
  published BOOLEAN NOT NULL DEFAULT FALSE
);
CREATE TABLE IF NOT EXISTS topics (
  id INT AUTO_INCREMENT PRIMARY KEY,
  period_id INT NOT NULL,
  name VARCHAR(100) NOT NULL,
  FOREIGN KEY (period_id) REFERENCES periods(id)
);
CREATE TABLE IF NOT EXISTS indicators (
  id INT AUTO_INCREMENT PRIMARY KEY,
  topic_id INT NOT NULL,
  name VARCHAR(150) NOT NULL,
  detail TEXT NOT NULL,
  weight DECIMAL(8,2) NOT NULL,
  score_type ENUM('scale4','boolean') NOT NULL,
  evidence_type ENUM('none','file','url') NOT NULL,
  evidence_required BOOLEAN NOT NULL DEFAULT FALSE,
  FOREIGN KEY (topic_id) REFERENCES topics(id)
);
CREATE TABLE IF NOT EXISTS participants (
  id INT AUTO_INCREMENT PRIMARY KEY,
  period_id INT NOT NULL,
  user_id INT NOT NULL,
  submitted BOOLEAN NOT NULL DEFAULT FALSE,
  UNIQUE (period_id,user_id),
  FOREIGN KEY (period_id) REFERENCES periods(id),
  FOREIGN KEY (user_id) REFERENCES users(id)
);
CREATE TABLE IF NOT EXISTS assignments (
  id INT AUTO_INCREMENT PRIMARY KEY,
  participant_id INT NOT NULL,
  evaluator_id INT NOT NULL,
  committee_role ENUM('chair','member') NOT NULL,
  comment TEXT,
  signature VARCHAR(100),
  submitted BOOLEAN NOT NULL DEFAULT FALSE,
  UNIQUE (participant_id,evaluator_id),
  FOREIGN KEY (participant_id) REFERENCES participants(id),
  FOREIGN KEY (evaluator_id) REFERENCES users(id)
);
CREATE TABLE IF NOT EXISTS self_scores (
  id INT AUTO_INCREMENT PRIMARY KEY,
  participant_id INT NOT NULL,
  indicator_id INT NOT NULL,
  score INT NOT NULL,
  description TEXT NOT NULL,
  evidence_url VARCHAR(1000) NOT NULL DEFAULT '',
  evidence_file VARCHAR(100),
  UNIQUE (participant_id,indicator_id),
  FOREIGN KEY (participant_id) REFERENCES participants(id),
  FOREIGN KEY (indicator_id) REFERENCES indicators(id)
);
CREATE TABLE IF NOT EXISTS scores (
  id INT AUTO_INCREMENT PRIMARY KEY,
  assignment_id INT NOT NULL,
  indicator_id INT NOT NULL,
  score INT NOT NULL,
  UNIQUE (assignment_id,indicator_id),
  FOREIGN KEY (assignment_id) REFERENCES assignments(id),
  FOREIGN KEY (indicator_id) REFERENCES indicators(id)
);

เข้าใจโค้ด (คนที่ 1 ต้องอธิบายกรรมการได้)

ตาราง เก็บอะไร สัมพันธ์กับ
users ผู้ใช้ทุกบทบาท (admin, evaluatee ผู้รับ, evaluator กรรมการ) —
periods รอบประเมิน วันเริ่ม–สิ้นสุด สถานะ draft/open/closed —
topics หัวข้อการประเมินในแต่ละรอบ period_id → periods
indicators ตัวชี้วัด น้ำหนัก ชนิดคะแนน (scale4 1–4 หรือ boolean มี/ไม่มี) ชนิดหลักฐาน topic_id → topics
participants ผู้รับที่อยู่ในรอบ period_id → periods, user_id → users
assignments กรรมการที่ถูกมอบหมายให้ผู้รับ หน้าที่ประธาน/กรรมการร่วม ความเห็น ลายเซ็น participant_id → participants, evaluator_id → users

  const today = new Date().toLocaleDateString('sv-SE', { timeZone: 'Asia/Bangkok' });
  check(
    period.status === 'open' && today >= period.start_date && today <= period.end_date,
    'รอบยังไม่เปิด หรืออยู่นอกวันประเมิน',
    403,
  );
}
function scoreValid(item, score) {
  return (
    Number.isInteger(score) &&
    (item.score_type === 'boolean' ? [0, 1].includes(score) : [1, 2, 3, 4].includes(score))
  );
}
function percentage(indicators, scores) {
  if (!indicators.length) return null;
  let sum = 0,
    weight = 0;
  for (const item of indicators) {
    const row = scores.find((s) => s.indicator_id === item.id);
    if (!row || !scoreValid(item, row.score)) return null;
    const max = item.score_type === 'boolean' ? 1 : 4;
    sum += (row.score / max) * Number(item.weight);
    weight += Number(item.weight);
  }
  return Math.round((sum / weight) * 10000) / 100;
}

const { settings } = require('./db');
async function seed() {
  const db = await mysql.createConnection({ ...settings, multipleStatements: true });
  try {
    await db.query(fs.readFileSync(path.join(__dirname, 'schema.sql'), 'utf8'));
    const users = [
      ['admin', 'Admin1234!', 'ฝ่ายบุคลากร', 'admin'],
      ['emp001', 'Emp1234!', 'ผู้รับหนึ่ง', 'evaluatee'],
      ['emp002', 'Emp1234!', 'ผู้รับสอง', 'evaluatee'],

      await db.execute(

backend/auth.js — ตรวจ token และบทบาท

📄 backend/auth.js

const jwt = require('jsonwebtoken');
const { query } = require('./db');
const { check, route } = require('./helpers');
const secret = process.env.JWT_SECRET;
if (!secret || secret.length < 32) throw Error('ตั้ง JWT_SECRET ใน docker-compose.yml ให้ยาวอย่างน้อย 32 ตัวอักษร');
const auth = route(async (req, res, next) => {
  let payload;
  try {
    payload = jwt.verify((req.headers.authorization || '').replace('Bearer ', ''), secret);
  } catch {
    check(false, 'กรุณาเข้าสู่ระบบ', 401);
  }
  const rows = await query(
    'SELECT id,username,full_name,department,position,role,active,must_change_password FROM users WHERE id=?',
    [payload.id],
  );
  check(rows.length && rows[0].active, 'บัญชีถูกปิดหรือไม่พบผู้ใช้', 401);
  req.user = rows[0];
  // บัญชีที่ยังไม่เปลี่ยนรหัสครั้งแรก ใช้ได้แค่ดูข้อมูลตัวเองกับเปลี่ยนรหัส
  check(
    !req.user.must_change_password ||
      (req.method === 'GET' && req.path === '/me') ||
      (req.method === 'PUT' && req.path === '/me/password'),
    'กรุณาเปลี่ยนรหัสผ่านครั้งแรกก่อนใช้งาน',
    403,
  );
  next();
});
function role(name) {
  return (req, res, next) =>
    req.user.role === name
      ? next()
      : res.status(403).json({ status: 'error', message: 'ไม่มีสิทธิ์', data: null });
}
function token(user) {
  return jwt.sign({ id: user.id }, secret, { expiresIn: '8h' });
}
module.exports = { auth, role, token };

เข้าใจโค้ด

  • jwt.sign({id}, secret, {expiresIn:'8h'}) สร้าง token ที่ ลงนาม ด้วย JWT_SECRET ใครแก้ token เองลายเซ็นจะไม่ตรง
  • auth อ่าน header Authorization: Bearer <token> → jwt.verify → หา user ในฐาน → เก็บไว้ที่ req.user ถ้าผิดตอบ 401
  • ถ้า must_change_password ยังเป็น 1 จะใช้ได้แค่ GET /me กับ PUT /me/password (บังคับเปลี่ยนรหัสครั้งแรก) ตอบ 403
  • role('admin') กันคนผิดบทบาท ตอบ 403
  • เปลี่ยนรหัสสำเร็จ → must_change_password เป็น 0 → token เดิมใช้ทุก API ได้ทันที ไม่ต้อง login ใหม่

const multer = require('multer');
const fs = require('node:fs');
const path = require('node:path');
const { randomUUID } = require('node:crypto');
const { check } = require('./helpers');
const folder = process.env.UPLOAD_DIR || path.join(__dirname, 'uploads');
fs.mkdirSync(folder, { recursive: true });
const upload = multer({
  storage: multer.memoryStorage(),
  limits: { fileSize: 5 * 1024 * 1024, files: 1 },
}).single('file');
function saveFile(file, signature = false) {
  check(file, 'เลือกไฟล์ก่อน');
  const b = file.buffer;
  let extension = '';
  if (b.subarray(0, 8).equals(Buffer.from([137, 80, 78, 71, 13, 10, 26, 10]))) extension = '.png';
  if (b[0] === 255 && b[1] === 216 && b[2] === 255) extension = '.jpg';
  if (b.subarray(0, 5).toString() === '%PDF-' && !signature) extension = '.pdf';
  check(extension, signature ? 'ลายเซ็นต้องเป็น PNG หรือ JPEG' : 'รับเฉพาะ PDF, PNG หรือ JPEG');
  if (signature) check(file.size <= 512 * 1024, 'ลายเซ็นต้องไม่เกิน 512 KB');
  const name = randomUUID() + extension;
  fs.writeFileSync(path.join(folder, name), b);
  return name;
}
module.exports = { upload, saveFile, folder };
  • multer.memoryStorage() รับไฟล์ไว้ในหน่วยความจำก่อน จำกัด 5 MB
  • ตรวจ ไบต์แรกของไฟล์ (magic number) ไม่เชื่อนามสกุล: PNG เริ่มด้วย 89 50 4E 47, JPEG FF D8 FF, PDF %PDF- กันคนเปลี่ยนนามสกุลไฟล์อันตราย
  • ตั้งชื่อไฟล์ใหม่ด้วย randomUUID() กันชื่อซ้ำและกันชื่อไฟล์แปลก ๆ

async function result(id) {
  const person = await getParticipant(id),
    period = await getPeriod(person.period_id),
    indicators = await items(period.id);
  const self = await query('SELECT * FROM self_scores WHERE participant_id=?', [id]);
  const committees = await query(
    'SELECT a.*,u.full_name FROM assignments a JOIN users u ON u.id=a.evaluator_id WHERE a.participant_id=? ORDER BY a.id',
    [id],
  );
  for (const c of committees) {
    c.scores = await query('SELECT * FROM scores WHERE assignment_id=?', [c.id]);
    c.percentage = percentage(indicators, c.scores);
  }
  const done =
    !!person.submitted &&
    committees.length > 0 &&
    committees.every((c) => c.submitted && c.percentage !== null);
  const total = done
    ? Math.round((committees.reduce((sum, c) => sum + c.percentage, 0) / committees.length) * 100) /
      100
    : null;
  return {
    person,
    period,
    indicators,
    self_scores: self,
    self_complete: indicators.filter((i) =>
      complete(
        i,
        self.find((s) => s.indicator_id === i.id),
      ),
    ).length,
    committees,
    total,
  };
}

const router = require('express').Router();
const { query } = require('../db');
const { role } = require('../auth');
const { ok, route } = require('../helpers');
// GET /api/stats — สรุปจำนวนผู้ใช้ตามบทบาท และจำนวนรอบตามสถานะ (admin)
router.get(
  '/stats',
  role('admin'),
  route(async (req, res) => {
    ok(res, {
      users: await query('SELECT role, COUNT(*) AS total FROM users GROUP BY role'),
      periods: await query('SELECT status, COUNT(*) AS total FROM periods GROUP BY status'),
    });
  }),
);
module.exports = router;

  • ถ้า Docker ใช้ได้แค่ MySQL → รัน MySQL ใน Docker แต่รัน backend/frontend ด้วย Node บนเครื่อง (ต้องเป็น Node 20.19 ขึ้นไป เพราะ Vite 7):
